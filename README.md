# 🐾 汪汪救援队 · 10以内加减法

一个给 4 岁左右小朋友玩的数学小游戏：跟着救援小狗们做“任务”，在玩中理解 **数数、加法（合起来变多）和减法（拿走变少）**。

**在线玩：** 打开本仓库的 GitHub Pages 地址即可（手机 / 平板 / 电脑都可以，建议平板横屏）。

## 玩法
| 任务 | 学什么 |
| --- | --- |
| 🦴 数一数 | 1–10 点数，一一对应 |
| ➕ 狗狗集合 | 加法：两组合在一起，一共有几个 |
| ➖ 骨头被吃掉 | 减法：拿走一些，还剩几个（有“被拿走”的动画） |
| 🏆 大挑战 | 加减法混合 |

## 为什么适合 4 岁孩子
- **具体实物 → 算式**：每道题先用小狗/骨头讲故事，再出现算式和“十格框”。
- **点一点就会数**：孩子点每一只小狗，屏幕会出现数字并大声读出来。
- **语音朗读题目**：不认字也能玩（使用浏览器自带中文语音）。
- **不怕答错**：答错会温柔提示，并自动带着孩子一起数一遍。
- **选择题 + 圆点**：答案按钮下有圆点，孩子可以对照数量。
- **奖励系统**：答对得星星，每 5 颗星解锁一位新队员（共 8 位）。
- **自动升级**：默认从 5 以内开始，连续答对后自动升级到 10 以内。
- **家长设置**（需家长算一道乘法进入）：范围、题量、语音、十格框。

## 技术
纯 HTML + CSS + JavaScript，无需安装，无外部依赖，可离线使用。小狗形象全部为 SVG 原创绘制，音效用 Web Audio 实时合成。

## 本地运行
直接双击 `index.html` 即可。
